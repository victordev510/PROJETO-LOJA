Bem-vindo(a) ao repositório da minha Loja Virtual, um projeto desenvolvido por mim durante minha jornada de aprendizado em Desenvolvimento de Software.


📌 Sobre o projeto

Este projeto consiste em uma loja virtual criada com o objetivo de colocar em prática meus conhecimentos em programação e desenvolvimento web.

Como estudante de desenvolvimento, estou sempre buscando aprender novas tecnologias, melhorar minhas habilidades e desenvolver projetos que contribuam para minha evolução profissional.

🛒 Exibição de produtos.
🔎 Navegação pela loja.
💻 Interface simples e intuitiva.
